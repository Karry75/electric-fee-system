## 技术速览

- **形态**：单文件静态看板（HTML + JavaScript + ECharts），数据以离线快照形式随页面加载，纯前端渲染、无后端依赖。
- **原理**：业务库（阿里云 AnalyticDB）→ Python 抽取/构建管线 → 脱敏聚合快照 → 静态页面；页面打开即渲染，支持按维度筛选与下钻。
- **用途**：电费管理系统静态快照版。
- **脱敏**：公开发布版本已移除数据库连接信息、账号口令与个人敏感字段，仅保留聚合指标。


本仓库仅托管 **电费管理系统** 的静态看板快照（GitHub Pages，`main` 分支 `/docs` 目录），用于展示与分享，**不含可执行后端与数据库配置**。

## 1. 系统是做什么的

打通「电费结算登记表」与「电费情况总库」之间的数据割裂，把网点 / 商户的电费结算集中到一个页面里看：

- **结算状态可视**：结算单进度、已结 / 待结一眼可见；
- **下次结算提前预警**：按结算周期推算到期日，集中列出待办；
- **费用结构分析**：按单位、缴费方式、费用类型拆分支出构成；
- **商户资料集中**：结算主体与资料的统计视图。

## 2. 技术原理（静态快照版）

- **原架构**：React 18 + Vite 前端 SPA + Flask 后端 API + 本地快照库，前后端分离，页面通过 `/api/*` 取数，另有认证与写操作接口；
- **快照做法**：页面结构与交互逻辑保留，**取数层改为读取本地 JSON**，把原本由后端接口返回的聚合结果固化为静态文件；
- **接口对齐**：`docs/js/app.js` 中统一封装请求方法，静态模式下命中本地数据映射，页面无需为静态化改写业务渲染代码；
- **图表本地化**：`docs/lib/echarts.min.js` 随仓库分发，无外部 CDN 请求，内网 / 离线环境同样可打开；
- **会话处理**：静态模式下不走登录流程，页面稳定停留在数据视图，不会因未登录反复跳转。

## 3. 内容

- `docs/index.html`：前端页面（对话式交互后端接口 → 改读本地 JSON，纯静态只读）
- `docs/data/*.json`：业务库聚合数据（已脱敏），含结算 KPI、结算单、电费预警、费用支出、商户资料统计等
- `docs/js/app.js`、`docs/css/style.css`、`docs/lib/echarts.min.js`：本地静态资源（无外部 CDN 依赖）

## 4. 数据说明

- 数据来源：生产业务库只读聚合（结算 KPI、电费预警、结算单、费用支出、商户资料统计等）
- 隐私处理：手机号 / 身份证 / 银行账号 / 凭证账号等敏感字段已掩码或移除，明细列表已截断为样例
- 站点为**只读快照**，登录、提交、导出、审核等写操作不可用
